# قائمة التجربة الميدانية — سوقي POS

> نفّذها على حسابات اختبار/نسخة معاينة قبل الإنتاج. لا تُجرّب حفظ فواتير حقيقية أو تغيير أسعار عامة على متجر حي أثناء الاختبار.

## الأجهزة والمشاركون

- جهاز Android حديث في Chrome، ثم ثبّت سوقي من زر «تثبيت التطبيق» وافتحه كـ PWA.
- جهاز iPhone في Safari، ثم استخدم مشاركة ← «إضافة إلى الشاشة الرئيسية» وافتح الأيقونة.
- إن توفر جهاز لوحي/قارئ باركود خارجي، ضمّه إلى الجولة.
- راقب 3–5 أمناء صندوق دون شرح مسبق؛ سجّل موضع التوقف والكلمة/الزر الذي لم يكن واضحًا. لا تُعدّل الواجهة أثناء الجولة، ثم عالج أكثر ثلاث نقاط تسبب الارتباك.

## 1) تشغيل الكاميرا ومسح المنتجات

| الخطوة | النتيجة المتوقعة | النتيجة الفعلية / ملاحظة |
| --- | --- | --- |
| افتح `/pos` واسمح بالكاميرا | تبدأ الكاميرا الخلفية تلقائيًا، ولا تحتاج إلى زر التقاط صورة | |
| امسح باركود منتج معروف | يظهر المنتج أسفل الكاميرا في الفاتورة مع السعر والكمية | |
| اترك الباركود أمام العدسة لثانيتين | لا تتكرر القراءة ما دام الباركود نفسه مستمرًا في الإطار | |
| أبعد الرمز ثم أعده | تُقبل قراءة جديدة ويزداد عدد القطع لهذا المنتج | |
| بدّل إلى الأمامية ثم ارجع للخلفية | يتغير التدفق وتستمر القراءة؛ الخلفية تكون المحددة افتراضيًا عند فتح شاشة جديدة | |
| ارفض إذن الكاميرا أو استخدم متصفحًا غير داعم | تظهر رسالة تشرح الإذن/سبب الفشل، إعادة المحاولة، التبديل، الإبلاغ والإدخال اليدوي | |
| جرّب إدخال باركود يدويًا وقارئًا خارجيًا | Enter أو زر «إضافة» يُدخل المنتج ولا يفتح لوحة المفاتيح تلقائيًا على الهاتف | |
| فعّل/أوقف الصوت والاهتزاز | يمكن تعطيلهما، ولا يتعطل المسح عند حجب الصوت أو الاهتزاز | |

## 2) السلة والفاتورة والحفظ

| الخطوة | النتيجة المتوقعة | النتيجة الفعلية / ملاحظة |
| --- | --- | --- |
| أضف صنفين مختلفين | تظهر جميع الأصناف تحت الكاميرا، ويحدث إجمالي الفاتورة | |
| كرر صنفًا ثم زد/أنقص الكمية واحذفه | تُحسب الوحدات كأعداد صحيحة، وتعمل أزرار التعديل والحذف والتراجع | |
| أضف منتجًا ثم جرّب Ctrl+Z | يُستعاد آخر إجراء للسلة دون تغيير الكتالوج | |
| اضغط Ctrl+Enter أو «حفظ الفاتورة» | تُسجل الفاتورة بعد تأكيد الخادم فقط، وتُمسح المسودة بعد النجاح | |
| اقطع الإنترنت وحاول البحث والحفظ | لا تُسجل فاتورة؛ تبقى المسودة على الجهاز وتظهر رسالة عدم الاتصال | |
| أعد الاتصال | لا تُرسل فاتورة تلقائيًا؛ افحص سجل الفواتير قبل إعادة محاولة عملية لم يصل تأكيدها | |
| سجّل الخروج ثم الدخول بمستخدم آخر على الجهاز نفسه | لا تظهر مسودة المستخدم الأول للمستخدم الثاني | |

## 3) الكتالوج وطلبات الأسعار

| الخطوة | النتيجة المتوقعة | النتيجة الفعلية / ملاحظة |
| --- | --- | --- |
| امسح باركودًا غير موجود | تتوقف الكاميرا ويظهر نموذج بالباركود، وحقلي الاسم والسعر فقط | |
| أرسل منتجًا جديدًا أو أضفه يدويًا/بالصوت | يُحفظ للكتالوج العام؛ يعود مسح الكاميرا بعد الحفظ في مسار الكاميرا | |
| افحص الباركود بحساب متجر اختبار ثانٍ | يظهر المنتج والسعر العام نفسيهما | |
| اقترح تغييرًا لسعر منتج موجود | يبقى السعر العام القديم حتى قرار مدير المنصة | |
| افتح الكتالوج من المتجر صاحب الطلب | يظهر السعر المقترح وحالة الطلب وتاريخ القرار إن وُجد | |
| افتح الكتالوج من متجر آخر | لا تظهر بيانات الطلب أو صاحبه أو حالته الخاصة بالمتجر الأول | |
| وافق/ارفض طلب السعر من المدير | تتحدث الحالة وسجل السعر والقرار والتاريخ، والموافقة تنعكس على السعر المشترك | |

## 4) الاشتراك ولوحة المدير

| الخطوة | النتيجة المتوقعة | النتيجة الفعلية / ملاحظة |
| --- | --- | --- |
| أرسل طلب تجديد من متجر اختبار | يظهر طلب واحد مع اسم المتجر وصاحب الطلب وملاحظته وتاريخه | |
| وافق بمدة محددة دون تسجيل دفع | تُمدد المدة، ويظل الدفع «غير مدفوع» حتى تأكيده يدويًا | |
| استخدم فلتر المدفوع/غير المدفوع وبحث المتجر | تتوافق أعداد البطاقات مع الصفوف الظاهرة | |
| سجّل دفعًا يدويًا ثم مدّد المدة | يتغير الدفع بفعل التأكيد اليدوي فقط؛ التمديد لا يمسح حالة الدفع | |
| ابحث بالمنتج/الباركود/المتجر في طلبات الأسعار | تظهر الحالة المعلقة أولًا، ثم السجل مع السابق والمقترح وصاحب الطلب وقرار المدير | |
| ابحث بالاسم/البريد/رقم المتجر في المستخدمين | يمكن الوصول للحساب، تغيير الدور أو حالة تفعيله من الصلاحيات الحالية | |

## 5) PWA والطباعة

| الخطوة | النتيجة المتوقعة | النتيجة الفعلية / ملاحظة |
| --- | --- | --- |
| ثبّت التطبيق على Android وiPhone | تظهر أيقونة سوقي ويفتح كتطبيق مستقل | |
| افتح التطبيق بعد تحميله مرة ثم اقطع الشبكة | يظهر هيكل التطبيق/صفحة offline، ولا تُعرض نتائج API قديمة كأنها حديثة | |
| افتح الإعدادات ومعاينة الإيصال | تظهر بيانات النشاط ومثال إيصال واضح، مع زري طباعة وإغلاق | |
| اطبع المعاينة | لا تُنشأ فاتورة أو عملية بيع، وتعمل نافذة الطباعة النظامية | |
| اختر جهاز Bluetooth | يظهر «تم اختياره» لا «متصل»؛ تحقق من الطباعة الفعلية حسب توافق الجهاز والمتصفح | |
| امنع النوافذ المنبثقة | تظهر رسالة تطلب السماح بها بدل فشل صامت | |
